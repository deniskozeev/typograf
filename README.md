# Типограф для macOS

Лёгкое нативное приложение в менюбаре: выделите текст в любом приложении,
нажмите хоткей (по умолчанию **⌃⌥T**) — текст будет типографирован
и заменён на месте. Правила — оригинальная библиотека
[typograf](https://github.com/typograf/typograf) (105 правил для русского
и английского), исполняемая системным JavaScriptCore. Никаких внешних
зависимостей и рантаймов.

## Сборка

```bash
./build.sh
```

Результат: `build/Typograf.app`. Требуется Xcode (Swift 5.9+, macOS 13+).

## Первый запуск

1. Откройте `Typograf.app` — в менюбаре появится иконка «t».
2. Приложение попросит разрешение «Универсальный доступ»
   (Настройки → Конфиденциальность и безопасность → Универсальный доступ).
   Без него нельзя читать выделение и заменять текст.
3. Выделите текст, нажмите ⌃⌥T — готово. На иконке в менюбаре на пару
   секунд появится зелёная точка-подтверждение (отключается в настройках).

Клик по иконке в менюбаре открывает настройки: хоткей, набор правил,
уведомление, автозапуск. Правый клик — меню с выходом.

## Как это работает

Хоткей регистрируется через Carbon `RegisterEventHotKey`. По нажатию
приложение эмулирует ⌘C, забирает выделение из буфера обмена, прогоняет
через typograf (JavaScriptCore), кладёт результат в буфер, эмулирует ⌘V
и восстанавливает прежнее содержимое буфера.

> После пересборки macOS может попросить выдать разрешение Accessibility
> заново — ad-hoc подпись меняется с каждой сборкой.

## Обновления и распространение

Автообновления — [Sparkle 2](https://sparkle-project.org), без Apple
Developer Program. Приложение раз в сутки проверяет
`https://github.com/deniskozeev/typograf/releases/latest/download/appcast.xml`
(ключ `SUFeedURL` в Info.plist); вручную — из меню правого клика по иконке
или во вкладке «О программе». Релизы подписываются EdDSA-ключом
(`SUPublicEDKey` в Info.plist, приватный — в Keychain; создан
`generate_keys` из Sparkle).

Выпуск релиза:

```bash
./release.sh 1.1.0
```

Скрипт поднимет версию, соберёт подписанный zip и `releases/appcast.xml`
и подскажет команды `git tag` + `gh release create` для публикации.
Репозиторий должен быть публичным, иначе Sparkle не сможет скачать ассеты.

`build.sh` подписывает приложение первым сертификатом подписи кода из
Keychain (удобно завести самоподписанный: Связка ключей → Ассистент
сертификации → «Создать сертификат» → тип «Подпись кода») — так подпись
стабильна между версиями и Accessibility не слетает. Без сертификата —
ad-hoc. Gatekeeper при первой установке скажет «не удаётся проверить
разработчика» — пользователю нужно разрешить в Настройках
(Конфиденциальность и безопасность → «Всё равно открыть»).

Обратная связь пользователей: кнопка «Сообщить об ошибке или пожелании»
во вкладке «О программе» открывает письмо на dakozeev@gmail.com с версией
приложения и macOS в подписи.
